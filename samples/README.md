# samples

Sanitized device output, supplied by the owner.

Each file is real command output with anything identifying removed: hostnames, addresses that map to a real network, community strings, descriptions naming people or sites. The parsers are built and verified against these.

Nothing in this directory is ever quoted into a commit message, a log entry, a record, or a reply. Read it for the work and leave it here.

`tests/golden/` will hold the expected record sets these produce, once T-005 establishes whether the reference parser can generate them.
